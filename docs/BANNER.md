# Banner tema (company profile)

Setiap tema punya banner cover-only yang memutar animasi pembukanya berulang.

- Komponen: `components/invitation/ThemeBanner.vue` (`<ThemeBanner theme="gerbang" couple="…" date="…" />`).
- Embed ke situs lain (mis. Astro): `<iframe src="https://DOMAIN/embed/banner/gerbang?couple=Raka%20%26%20Sinta&date=20%20Des%202026" style="width:100%;height:420px;border:0" loading="lazy"></iframe>`
- ID tema: classic, minimal, floral, luxury, gerbang, amplop, sinematik, garden, jawa, celestial, watercolor.
